# Keyboard shortcuts

From the menus of Fignimble (generated from the app's menu definitions).

On Windows and Linux the editor has the same shortcuts with <kbd>Ctrl</kbd> for <kbd>⌘</kbd> and <kbd>Alt</kbd>
for <kbd>⌥</kbd> (<kbd>⇧</kbd> is <kbd>Shift</kbd>). Its **File** menu also holds Check Packages and Quit
(<kbd>Ctrl</kbd>+<kbd>Q</kbd>), and its **Terminal** menu opens the system's terminal
(<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>T</kbd>); see [Windows and Linux](../getting-started/windows-linux.md).

## Canvas

| Action | Keys |
|---|---|
| Select, text, line, arrow, rectangle, ellipse, bracket, pen, zoom tools | <kbd>V</kbd> <kbd>T</kbd> <kbd>L</kbd> <kbd>A</kbd> <kbd>R</kbd> <kbd>E</kbd> <kbd>B</kbd> <kbd>P</kbd> <kbd>Z</kbd> |
| Nudge 0.5 mm (5 mm, 0.1 mm) | arrow keys (with <kbd>⇧</kbd>, with <kbd>⌥</kbd>) |
| Turn snapping off while dragging | hold <kbd>⌘</kbd> |
| Keep proportions while resizing; 45° lines | hold <kbd>⇧</kbd> |
| Move one panel letter (instead of all) | <kbd>⌥</kbd>-drag |
| Pan | scroll, or hold <kbd>Space</kbd> and drag |
| Zoom | <kbd>⌘</kbd>-scroll or pinch |
| Retype a text; open a panel's code; type in a table cell; open a figure placed whole; edit a text's Markdown file | double-click |
| Unlink a panel letter from its panel (or link it again) | double-click the letter |
| Back from a text in a panel to the panel | <kbd>Esc</kbd> |
